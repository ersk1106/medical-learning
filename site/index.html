医療知識 学習ロードマップ

医療系動画の制作者が、医師・看護師・医事課と会話できるようになり、企画と台本を医学的に正確に作れるようになるための教材です。毎日17:50ごろに1手技ずつレッスンが届き、このサイトに追加されます。

使い方

  • 上のメニューから各回を開けます。各回は「どんな時に必要か → 解剖 → 手術の流れ → 入院生活 → 合併症 → 素朴な疑問 → 説明と同意 → 点数 → 用語 → 動画制作の視点」の順に並んでいます
  • 総論には、診療科の全体像・医事課の仕事・職種別の説明義務をまとめています
  • 質問は届いたレッスンに返信するか、元のチャットで聞いてください
